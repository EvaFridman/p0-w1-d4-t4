## Контекст

Ты раскидала цвета по всему CSS, а потом заказчик попросил «сделать брендовый синий чуть
темнее» — и ты ищешь этот цвет в двадцати местах. В CSS есть способ задать значение один раз и
переиспользовать везде: переменные. На лекции их не показывали — разбираешься сама.

```
:root {
  --brand: #...;   ← одна точка правды для цвета
}
.btn { color: var(--brand); }

меняешь переменную в одном месте → меняется везде
ищешь сама: CSS custom properties, var(), :root
```

## Что нужно сделать

Взять свой стилизованный проект из t3 (или t2) и вынести повторяющиеся значения — цвета,
отступы, радиусы — в CSS-переменные, объявленные в `:root`, и использовать через `var()`.
Показать, что изменение одной переменной меняет вид во всех местах сразу. Никакого JS.

## Релизы

### Release 1 — переменные цвета
Найти, что такое CSS custom properties, `:root` и `var()`. Вынести 3–4 основных цвета в
переменные. Заменить все хардкод-цвета на `var(--...)`. В `CSS.md` — как это работает.

### Release 2 — токены отступов
Вынести в переменные базовые отступы и радиус скруглений. Использовать их в карточках/полях.
Изменить значение одной переменной и убедиться, что поменялось везде разом.

### Release 3 — запасное значение
Раскопать, что `var()` умеет принимать fallback (`var(--x, значение-по-умолчанию)`), и где это
полезно. Применить хотя бы раз. В `CSS.md` объяснить, зачем нужен fallback.

## Критерии приёмки

* Повторяющиеся цвета и отступы вынесены в переменные `:root`, используются через `var()`.
* Изменение одной переменной видимо меняет несколько мест сразу.
* Применён `var()` с fallback, в `CSS.md` объяснено зачем.
* Ни строки JavaScript.
