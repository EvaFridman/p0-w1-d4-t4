CSS custom properties (они же переменные) - сущности, создаваемые для хранения различных значений, которые можно повторно использовать в разных частях стилей.

var () - встроенная функция для вызова переменной.

:root - псевдокласс с глобальной видимостью. Любые переменные, объявленные внутри :root, становятся доступными для использования на всей странице.
